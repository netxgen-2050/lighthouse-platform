# lighthouse-platform

Plataforma de NetX para el Lighthouse (Soluna). Next.js en Vercel, desarrollada por agentes de Claude Code con revisión humana.

- Reglas del repo: [`CLAUDE.md`](CLAUDE.md)
- Cómo trabajan los agentes: [`docs/agentes.md`](docs/agentes.md)
- Cambios en curso: `openspec/changes/`

```bash
pnpm install
pnpm dev          # http://localhost:3000
pnpm verificar    # lint + tipos + tests
pnpm noche <id>   # corrida nocturna de los agentes
```
