Cómo decidimos en el Lighthouse

Cada nivel se organiza igual que el de arriba: el común tiene sus círculos, cada tribu tiene los suyos, y cada círculo tiene sus roles. Tocá cualquier círculo para entrar; tocá el fondo o las migas para volver a salir.

Datos inventados para el boceto · no es la pantalla real
Niveles que se repiten

Común → tribu → círculo → rol. El mismo patrón en cada escala: propósito, dominio, roles y decisiones.

Propósito

Cada círculo existe por una razón: tierra, agua, economía, comunidad, conocimiento o gobierno. La lente Propósitos lo colorea.

Doble enlace

Cada tribu manda un enlace al consejo y el común manda un enlace a cada tribu. Las decisiones suben y bajan por esos enlaces.

Desde mí

Una persona participa en varios círculos a la vez, en niveles distintos. La lente Desde mí la ubica en todos.
